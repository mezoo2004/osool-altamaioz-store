# Osool Altamaioz — E-commerce Project

## Official brand name

**Arabic:** اصول التميز  
**English:** Osool Altamaioz

> Critical spelling rule: never write `أصول التميز` and never change the English spelling.

## How to start in Cursor

1. Extract this folder.
2. Open the **whole `osool-altamaioz-store` folder** in Cursor.
3. Open Cursor Agent.
4. Send only this message:

```text
Read CURSOR_MASTER_PROMPT.md, START_HERE.md, the .cursor rules, and all project references. Then execute the master prompt from Phase 0 onward. Work on the files; do not just explain the plan.
```

Cursor should inspect the reference files before creating the application.
