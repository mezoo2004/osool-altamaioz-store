# Homepage development imagery

Replace remote URLs in `src/lib/home/home-images.ts` with official photography here.

## Structure

```
hero/
  hero-main.webp
spaces/
  majlis.webp
  living-room.webp
  bedroom.webp
  kitchen.webp
  office.webp
  restaurant.webp
  retail.webp
  facade.webp
  garden.webp
scene/
  majlis-scene.webp
```

Set `preferLocal={true}` on `HomeImage` components when local files are ready.
