## Brand naming

Arabic: **اصول التميز**  
English: **Osool Altamaioz**

## Direction

- Arabic is primary and uses RTL.
- English uses LTR.
- AR/EN language switching is required.
- Desktop and mobile are both first-class experiences.

## Implementation rule

Use Figma as the visual/UX source of truth. Do not replace it with a generic ecommerce template.

If Cursor has direct Figma/MCP access, it should inspect the Figma file before UI implementation. If it cannot access Figma, continue using the written requirements and ask for exported screen images only if genuinely necessary.
